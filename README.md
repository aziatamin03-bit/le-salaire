# OBAYOLI - نظام إدارة الموارد البشرية والرواتب (HR & Payroll Management)

نظام متكامل واحترافي لإدارة الموارد البشرية والرواتب بالمغرب مع دعم التخزين السحابي عبر Firebase Firestore وإمكانية العمل دون اتصال بالإنترنت.

---

## 🌟 المميزات الرئيسية (Key Features)

1. **إدارة الرواتب (Payroll Management)**:
   - احتساب الراتب اليومي تلقائياً: `الراتب الشهري ÷ 26`.
   - احتساب راتب الساعة تلقائياً: `الراتب اليومي ÷ 8`.
   - خصم الغيابات، المرض، والتوقيف المؤقت عن العمل (*Mise à pied*).
   - احتساب أيام العمل الإضافية وأيام الراحة.
   - كشف صافي الراتب بدقة مع خيارات تصدير PDF.

2. **التخطيط وجداول العمل الأسبوعية (Weekly Scheduling)**:
   - جداول الورديات وتوزيع ساعات العمل لقسم المطبخ (`POST CUISINE`) والأقسام الأخرى (`BAR`, `CAISSE`, `MENAGE`, `SERVEC`).
   - خيارات الورديات، والراحة (`REST`)، والإجازة (`OFF`).
   - تنزيل جدول التخطيط الأسبوعي بصيغة PDF.

3. **تسجيل الحضور والغياب (Attendance Tracking)**:
   - تسجيل أوقات الدخول والخروج وحساب ساعات العمل تلقائياً.
   - حالات الحضور: حاضر، متأخر، مريض، غائب.
   - أرشيف وسجل يومي للحضور.

4. **إدارة الإجازات (Leave Requests)**:
   - طلبات الإجازة السنوية، الاستثنائية، والمرضية.
   - حساب الأيام المتبقية والموافقة أو الرفض.

5. **العطل الرسمية بالمغرب (Moroccan Public Holidays)**:
   - قائمة العطل الوطنية الثابتة والعطل الدينية.
   - تخطيط عمل الموظفين في أيام العطل والإجازات السنوية.

6. **التقارير والإحصائيات (Reports & Charts)**:
   - رسوم بيانية لتوزيع الرواتب وإحصائيات الحضور عبر Chart.js.
   - تقارير شهرية مفصلة وتصدير PDF.

7. **قاعدة بيانات سحابية (Firebase Firestore Database)**:
   - مزامنة سحابية مع قاعدة بيانات Firebase Firestore.
   - دعم التخزين المحلي والنسخ الاحتياطي بصيغة JSON.

## 🚀 التشغيل المحلي (Getting Started)

### المتطلبات
- Node.js (v18+)
- npm أو bun

### التثبيت والتشغيل
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# أو تشغيل الخادم الثابت
node server.cjs
```

يفتح التطبيق تلقائياً على الرابط: `http://localhost:3000`

## 📁 هيكل المشروع (Project Structure)

- `index.html`: واجهة المستخدم الرئيسية وهيكل الصفحات.
- `style.css`: التنسيقات والتصميم المتجاوب.
- `app.js`: محرك المنطق وحسابات الرواتب وإدارة الواجهات.
- `cloud-client.js`: جسر المزامنة مع قاعدة بيانات Firebase Firestore.
- `permissions.js`: نظام صلاحيات المستخدمين.
- `firebase-applet-config.json`: إعدادات وتكوين Firebase.
- `firestore.rules`: قواعد الأمان لـ Firestore.
- `server.cjs`: خادم Node.js الثابت.
